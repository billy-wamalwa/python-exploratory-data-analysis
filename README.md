# Exploratory Data Analysis (EDA) & Visualization

## Project Overview
This project demonstrates Exploratory Data Analysis (EDA) using Python and Jupyter Notebook. It explores applicant data to understand its structure, identify patterns and visualise important findings.

# Objectives
Understand the structure and characteristics of the dataset.
Analyse applicant distributions across universities and application statuses.
Explore patterns and relationships within the data.
Create meaningful charts and visualisations.
Generate insights to support data-driven decision-making.
# Tools and Technologies
Python — Programming language for data analysis.
Jupyter Notebook — Interactive environment for writing and executing code.
Pandas — Data manipulation and analysis.
Matplotlib — Data visualisation.
Seaborn — Statistical data visualisation.

# Analysis Performed
Applicant distribution analysis.
University and application-status comparisons.
Data visualisation using charts and graphs.
Project Files
Week2_EDA_BilliumWamalwa.ipynb — Notebook containing the analysis, code, and visualisations.
# Key Learning Outcomes

This project demonstrates practical skills in exploratory data analysis, data-quality assessment, descriptive statistics, data visualisation, and communicating insights using Python.
